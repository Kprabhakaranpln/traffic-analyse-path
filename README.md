Traffic Sign Recognition is a computer vision and deep learning project built with Python, TensorFlow/Keras, and OpenCV. It allows autonomous systems and driver-assistance solutions to accurately classify road signs from images across 43 different categories in real time[cite: 1].

## 🛠️ Features

* **Multi-Class Classification:** Identifies 43 distinct traffic sign categories from the GTSRB dataset with high accuracy[cite: 1].
* **Automated Preprocessing:** Applies histogram equalization, color conversion (HSV/grayscale), and scaling to handle poor lighting and weather conditions[cite: 1].
* **Real-Time Inference:** Fast model evaluation capable of processing uploaded images or video stream frames.
* **Data Augmentation:** Trained with rotation, zoom, shear, and shift transformations to prevent overfitting and boost generalization[cite: 1].
